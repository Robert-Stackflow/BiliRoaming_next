# 哔哩哔哩 9.12.0 安装版

在已交付的 r33 功能基础上适配官方 arm64 9.12.0（原版 versionCode 9120300）。保留默认最高可用 SDR 画质/帧率、音质和直播画质策略、广告净化，以及“不修改/恢复系统默认”详情动画选项；不包含 Hero 或菜单样式改写。

## 本次修复

- **禁止首页自动刷新**：9.12/9.13 推荐流配置的 Kotlin 字段已被 R8 改名。改用 `SerializedName`/`JSONField` 中的接口字段名设置后台、页面返回和行为刷新时限，并关闭 `is_back_auto_refresh`。缓存读取也处理配置；对自动刷新组件和 ViewModel 的明确自动刷新原因增加拦截。保留首次加载、下拉刷新、上拉加载、点击刷新和登录状态变化。
- **首页游戏中心**：新入口使用 `action://game_center/home/menu`，会由首页菜单提供器合并网络、缓存和内置菜单。原实现仅过滤旧 URI，且误把游戏详情页的三个 `tri_*` 控件当作首页入口。本次在菜单提供器中过滤游戏路由，移除这些无关控件拦截；消息等其他菜单保留。
- **版本兼容**：竖屏入口按资源名称解析，不复用跨版本数值 ID；播放器下方广告提供器兼容 9.12 的 `r10.n$e` 和 9.13 的 `k10.p$e`，先检查参数签名。
- **首次启动**：9.12 的符号适配表由连接的真机扫描生成，只含类/方法名。按原版 APK 的大小和 CRC 指纹加载，避免每次安装后在启动主线程扫描全部 dex；不匹配的原版继续原有发现流程。

9.12 原版 SHA-256：`cbd61b29098e3a7deb7afb791a9e875ec77c31be8ca5cf0423f36d1296d19c16`。

原版来源：[哔哩哔哩官方下载地址](https://dl.hdslb.com/mobile/pack/android64/28383822/iBiliPlayer-release-9.12.0-b28383822.apk)。原版 APK 的 v2/v3 签名验证通过，证书 SHA-256 为 `93ba270f5521139ecafe4bb638ac5b1198bc548f62d9fd8f8580a079faf5910e`。

安装版使用现有个人签名和 Release 模块。为覆盖当前 9.13.0 并保留数据，外层安装包 versionCode 设为 9130500；应用显示版本仍为 9.12.0，内嵌原版 APK 不变。该内部编号调整不代表客户端功能版本升为 9.13。
